## 3. What v1.3 built

**Flow:** Meta → n8n (verify, store, dedupe) → n8n claims the message → `POST /api/hazem/turns`
→ .NET decides (only a test echo until TASK 04) → n8n sends each action to Meta (24 h window,
approved templates, idempotency) → `POST /api/hazem/send-results` → message marked processed.
.NET can also ask n8n to send (`POST /webhook/hazem-internal-send`).

**Database (`database/migrations/0003_hazem_api.sql`):**
- schema `hazem` (`settings`, `turns`, `send_results`) for the API, role `office_api`
  (created in `infra/postgres/init`); `office_app` (n8n) and `office_api` (.NET) cannot reach
  each other's schema — enforced by PostgreSQL.
- `app.wa_turns_claim` (pending text → processing; stuck > 5 min reclaimed) and
  `app.wa_turns_finish` (processed / failed / back to pending).
- `whatsapp.dry_run` setting (sends recorded without Meta; must stay `false`);
  `whatsapp.echo_test_enabled` removed.

**Backend (`backend/`, .NET 10):** structure taken from `archive/task02-dotnet`, no Meta code.
`Office.Core` (validation, `TurnResponder` = echo, `TurnService`, `OutboundService`),
`Office.Infrastructure` (EF Core on `hazem`, `N8nWhatsAppGateway`), `Office.Api` (two endpoints,
`X-Hazem-Token` checked in constant time, `/health/live`, `/health/ready`), `Office.Cli`
(`send-test`). Docker service `api`: no host port, never behind the tunnel.

**n8n (`n8n/workflows/`):** new `WA-FORWARD-TURN` (after inbound + every minute + manual),
`WA-HANDLE-TURN`, `WA-SEND-ACTION`, `WA-INTERNAL-SEND` (header-auth webhook). Changed
`META-WA-INBOUND` (forwards to the API), `META-WA-SEND-MESSAGE` / `-TEMPLATE` (dry run).
Removed `WA-ECHO-TEST` (still in the n8n database, unpublished).
`n8n-import` now creates the credentials from `.env` (`office-postgres-app`, `hazem-api`,
`hazem-internal-send`) and restarts n8n when it publishes a schedule or webhook.

**Secrets (new, in `.env`, generated, never printed):** `OFFICE_API_PASSWORD`,
`HAZEM_API_TOKEN` (n8n → API), `N8N_INTERNAL_SEND_TOKEN` (API → n8n). Preflight checks them.
`.env` backups: `K:\tmp\env.before-v13.bak`.
